# 🎯 Industrial Engineering Archery & Quiz Game (Python / Tkinter)

An interactive desktop mini-game built with Python that combines core Industrial Engineering concepts (operations research, time study, and system optimization) with engaging gameplay!

---

## 🎮 Game Features & Mechanics
* **Archery Mechanic:** A dynamic moving bow mechanic where timing your arrow release directly affects your performance.
* **Engineering Quiz:** Randomized industrial engineering questions testing production planning and optimization knowledge.
* **Health & Cooldown System:** 5 hearts with a 3-wrong penalty threshold, plus a 5-minute cooldown mechanism (`game_cooldown.txt`) when hearts run out.
* **Scoring System:** 
  * Archery Hit: **+50 pts**
  * Correct Answer: **+100 pts**
  * Wrong Answer: **-50 pts**
* **Distraction-Free UI:** Clean, custom pink-themed interface designed for smooth interaction.
